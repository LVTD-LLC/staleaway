# Content inventory comparison tool

Public intent owner: `/tools/content-inventory-compare`. The existing sitemap guide remains the owner of finding/selecting an XML sitemap and import readiness; the checklist owns review/checklist/cadence guidance.

Information gain: a working, browser-only three-list membership comparison turns intended inventory, selected sitemap page URLs and actual imported records into an exact URL follow-up list. Equal totals cannot substitute for membership checks. No live checking, indexing diagnosis, automatic repair or account synchronization is offered.

## Product and interaction contract

- Three required newline-separated lists; public HTTP/HTTPS page URLs only, no XML/CSV import or file upload.
- Exact trimmed strings, no inferred redirect/canonical/encoding/trailing-slash equivalence. Explicit bounded input and displayed/export scope.
- All seven nonempty membership combinations, duplicates/blank accounting and neutral manual follow-up.
- Complete local CSV; safe text rendering, no pasted inputs in URLs, storage, analytics or requests. Editing/clearing invalidates prior results and downloads.
- Prefilled fictional example, keyboard/label/status support, disabled-JavaScript manual worksheet.
- No change to PR8 reminder workflow, customer records, legacy storage, free features or billing removal.

## Sources and maintenance

Google's [sitemap overview](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview) explains discovery is not guaranteed crawling/indexing. [Tulane's content audit guidance](https://communications.tulane.edu/drupal-guide/web-content-management/content-audit) distinguishes gathering content from evaluating it. Checked November 1, 2026. Product boundaries derive from current `PRODUCT.md`, `core/tasks.py`, `core/views.py` and existing public sitemap guidance, not customer tests.

Interaction references: the existing Staleaway planner's fictional example/native download; URLsCheck's explicit comparison limits; WordSpinner's categorized differences/CSV. These do not establish market-wide uniqueness or runtime competitor performance. Our exact matching deliberately avoids inferred URL equivalence.

No external constants or paid per-use API. Recheck browser parsing/interaction and explanatory copy when workflow changes. Raw research, measurements and experiment history remain in the existing private Rowset SEO dataset referenced by `.seo/config.json`.
